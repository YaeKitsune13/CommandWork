# Сервис для прослушивания музыки (Dinisify)

## 1. Функции Гостя (неавторизованный пользователь)

1.1. Регистрация (почта/телефон)

1.2. Авторизация (вход в систему)

1.3. Восстановление пароля

1.4. Прослушивание музыки (с ограничениями — реклама/урезанный каталог)

1.5. Поиск треков/исполнителей/альбомов

1.6. Просмотр публичных плейлистов

1.7. Просмотр чартов (топ треков/альбомов/исполнителей)

## 2. Функции Авторизированного пользователя

2.1. Прослушивание музыки (полный доступ)

2.2. Профиль
- Редактирование личных данных (аватар, никнейм, email)
- Смена пароля
- Настройки приватности
- История прослушиваний

2.3. Плейлисты
- Создание/редактирование/удаление своих плейлистов
- Добавление/удаление треков из плейлиста
- Публичный/приватный доступ к плейлисту
- Совместные плейлисты

2.4. Рекомендации
- На основе истории прослушиваний
- На основе лайков
- Похожие исполнители/жанры

2.5. Добавление своих музыкальных треков на площадку
- Загрузка аудиофайла
- Указание метаданных (название, исполнитель, жанр, обложка)
- Отправка на модерацию

2.6. Чарты
- Глобальные чарты (топ-100 по стране/миру)
- Персональные чарты (среди друзей/подписок)
- Чарты по жанрам
- Фильтр по периоду (день/неделя/месяц/год)

2.7. Социальные функции
- Подписка на пользователей/исполнителей
- Лайки/дизлайки треков
- Комментарии под треками

## 3. Функции Модератора

3.1. Просмотр треков, ожидающих модерации

3.2. Добавление/Редактирование треков

3.3. Отклонение треков (с указанием причины)

3.4. Блокировка/удаление некорректного контента

3.5. Просмотр жалоб пользователей

3.6. Просмотр статистики платформы (опционально)

## 4. Функции Администратора

4.1. Управление пользователями (блокировка, роли)

4.2. Управление модераторами

4.3. Просмотр общей аналитики сервиса

4.4. Управление жанрами/категориями
